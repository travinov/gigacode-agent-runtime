# GigaCode Agent Runtime

Local MCP-first runtime for declarative multi-agent workflows executed through
the corporate GigaCode CLI.

The project is currently under active development. Version 1 targets macOS
`x86_64`, Python 3.11–3.14, local MCP over `stdio`, resumable run state, and an
offline ZIP installer.

The approved architecture and implementation plan are available in:

- `docs/superpowers/specs/2026-07-24-gigacode-agent-runtime-design.md`;
- `docs/superpowers/plans/2026-07-24-gigacode-agent-runtime-v1-implementation.md`.

No production runtime is available yet.
